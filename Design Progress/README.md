# AutoCAD Design Progress

## Day 1 — Initial Casing Development

During the first day, I familiarized myself with several fundamental AutoCAD commands and began developing the initial geometry for the metronome casing.

### Work Completed

- Practiced fundamental AutoCAD modelling commands and workflows.
- Created 2D rectangular profiles using the `RECTANG` command.
- Developed 3D rectangular geometry using the `BOX` command.
- Used the `SUBTRACT` command to remove material and create a hollow enclosure.
- Developed the initial outer geometry of the metronome casing.
- Created a rectangular opening on the rear of the casing to accommodate the PCB.

## Day 2 — PCB Integration

The second day focused on modifying the casing to accommodate the PCB and improving the design for component integration.

### Work Completed

- Positioned the slot to provide access for PCB installation while maintaining the overall casing structure.
- Continued refining the casing geometry to support the integration of the electronic components.
