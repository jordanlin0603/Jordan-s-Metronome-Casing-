# Jordan's Metronome Casing

Custom 3D-printed enclosure designed in AutoCAD for the metronome
electronics developed in Morgan's Metronome v1.0 project.

This project focuses on designing a functional and practical casing
that accommodates the PCB while providing access for installation and
maintaining a clean external form.

## Features

- Custom 3D-printed metronome enclosure
- Hollow internal enclosure for housing electronic components
- Rear PCB access opening
- 50 mm PCB insertion slot
- Designed around the existing metronome PCB
- Dimensioned and developed using AutoCAD
- Iterative design process documented through CAD progress screenshots

## Design

The casing is being developed as a custom enclosure for the metronome
electronics. The design process involves creating the outer enclosure,
removing internal material to form a hollow housing, and adding
openings required for PCB installation and access.

The design is being developed progressively in AutoCAD, with each major
iteration documented in the Design Progress folder.

## Development

The project began by learning and applying fundamental AutoCAD
modelling techniques.

Initial development included:

- Creating rectangular profiles using `RECTANG`
- Creating 3D geometry using `BOX`
- Using `SUBTRACT` to create the hollow enclosure
- Developing the initial outer casing geometry
- Creating a rear opening for the PCB
- Adding a 50 mm slot for PCB insertion

Further development will focus on refining the casing geometry,
improving component fitment, and preparing the design for 3D printing.
